# Инструкция пользователя ZiCode (OpenCode для Android и Windows)

## 1. Установка и запуск

### На Windows 10 / 11 (x64)
1. **Портативная версия (без установки)**:
   - Скачайте [`ZiCode-Portable-2.3.0-x64.exe`](https://github.com/zigorminsk-debug/zicode/releases/download/v2.3.0/ZiCode-Portable-2.3.0-x64.exe) и запустите файл.
2. **Установщик (Setup)**:
   - Скачайте [`ZiCode-Setup-2.3.0-x64.exe`](https://github.com/zigorminsk-debug/zicode/releases/download/v2.3.0/ZiCode-Setup-2.3.0-x64.exe), выберите папку установки — на Рабочем столе и в меню «Пуск» появится ярлык **ZiCode (OpenCode)**.
   - Если Windows SmartScreen покажет предупреждение о новом издателе, нажмите **«Подробнее» → «Выполнить в любом случае»**.

### На Android (смартфон или планшет, Android 7.0+)
1. Скачайте [`ZiCode-Android-v2.3.0-Signed-Release.apk`](https://github.com/zigorminsk-debug/zicode/releases/download/v2.3.0/ZiCode-Android-v2.3.0-Signed-Release.apk).
2. Откройте скачанный `.apk` и разрешите установку из вашего браузера/проводника.
3. Приложение подписано постоянным релизным сертификатом (`SHA256: 47:D7:9F:24:...`), поэтому все последующие обновления устанавливаются поверх без удаления данных.

## 2. Как устроен интерфейс программы

Интерфейс разделён на 4 зоны:

### A. Верхняя панель управления
1. **Переключатель агентов (`BUILD` | `PLAN` | `GENERAL` | `EXPLORE`)**:
   - **`BUILD`** *(по умолчанию)* — режим полной разработки: агент может создавать, редактировать, патчить файлы и выполнять команды в терминале.
   - **`PLAN`** — режим архитектора **только для чтения**: агент изучает код и строит план, но ему запрещено изменять файлы проекта. Переключаться между `BUILD` и `PLAN` можно клавишей **`Tab`** или кликом мыши/касанием.
   - **`GENERAL`** и **`EXPLORE`** — специализированные сабагенты для многошаговых задач и быстрого поиска по файлам (`glob`, `grep`, `read`).
2. **Выбор ИИ-модели (кнопка с названием модели и значком `FREE $0`)**:
   - Нажмите на текущую модель (или нажмите `Ctrl+K`, либо введите `/models`), чтобы открыть каталог из **40+ бесплатных моделей** (`Big Pickle`, `Beam Free 1M`, `DeepSeek V4.1 Flash Free`, `GLM-5.3-Flash Free`, `MiMo-V2.6-Flash Free`, `Flint 40B Free`, `Nemotron 3 Ultra Free`, `OpenRouter Free`, `GLM-4.7-Flash` и др.).
   - Кнопка **`Sync models.dev`** синхронизирует свежий список моделей напрямую с каталога `https://models.dev`.
3. **Effort (`Low` / `Medium` / `High` / `XHigh` / `Max`)**:
   - Управляет глубиной рассуждений (Reasoning) перед ответом.
4. **Кнопки справа**:
   - **`↶` / `↷` (`/undo` и `/redo`)** — откат последнего действия агента вместе с восстановлением изменённых файлов из снимка (Snapshot).
   - **`STUDIO GUI` / `TUI MODE`** — переключение между современным графическим режимом и классическим терминальным видом OpenCode.
   - **`🎨` (`/themes`)** — смена цветовой темы (OpenCode Dark, Tokyo Night, Catppuccin, Dracula, Gruvbox, Nord, GitHub Dark, Rosé Pine, SynthWave '84, OpenCode Light).
   - **`⚙️` (Настройки)** — ввод собственных API-ключей (опционально; для бесплатных моделей OpenCode Zen по умолчанию уже стоит публичный ключ `public`).

---

### B. Левая боковая панель (6 вкладок)
- **Файлы (`Files`)**: Дерево файлов рабочей области. Кнопка **«+ Новый»** создаёт файл, клик по файлу открывает его во встроенном редакторе кода.
- **Сессии (`Sessions`)**: Список ваших диалогов. Кнопка **«+ Новая»** создаёт чистую сессию.
- **Задачи (`Todos`)**: Чек-лист задач текущей сессии, который агент ведёт через инструмент `todowrite` (можно также кликать по задачам вручную для смены статуса `pending` → `in_progress` → `completed`).
- **Снимки (`Snapshots`)**: Точки восстановления файлов перед каждым запросом. Нажмите **«Восстановить»**, чтобы вернуть файлы к любому моменту времени.
- **MCP**: Подключённые серверы Model Context Protocol (`OpenCode Workspace FS`, `OpenCode Git Inspector`, `Context7 Docs MCP`).
- **Сборки (`Builds`)**: Прямые ссылки на скачивание актуальных `.apk` и `.exe`.

---

### C. Центральная рабочая область (4 вкладки)
1. **Диалог с агентом**:
   - Показывает сообщения, раскрывающийся блок **«🧠 Мыслительный процесс модели (Reasoning Trace)»** и карточки выполненных инструментов (**`🔧 glob`**, **`🔧 read`**, **`🔧 write`**, **`🔧 edit`**, **`🔧 bash`**, **`🔧 lsp_diagnostics`**) с цветным `diff` изменений.
2. **Редактор (`Editor`)**:
   - Позволяет просматривать и редактировать любой файл проекта вручную, а также нажать **«Спросить OpenCode об этом файле»**.
3. **Diff изменений (`Diff`)**:
   - Показывает все добавленные, изменённые и удалённые строки кода (`+` / `-`) за текущую сессию.
4. **Терминал (кнопка `Терминал` справа вверху)**:
   - Открывает встроенную консоль (`PowerShell` / `CMD` на Windows, `/system/bin/sh` на Android), где можно выполнять любые команды (`git status`, `ls`, `cat`, `npm test` и т.д.).

## 3. Как правильно ставить задачи агенту (Примеры)

В нижней строке ввода поддерживаются **обычные текстовые запросы**, **упоминания файлов через `@`**, **слэш-команды через `/`** и **прямые команды терминала через `!`**:

### 1. Прикрепление файлов через `@`
Начните печатать символ **`@`** — появится всплывающий список файлов проекта:
- `Проанализируй файл @src/example/calculator.ts и добавь функцию возведения в степень`
- `Проверь конфигурацию в @opencode.json`

### 2. Создание и редактирование кода (в режиме `BUILD`)
Убедитесь, что вверху выбран агент **`BUILD`** (если выбран `PLAN` или `GENERAL`, нажмите на кнопку **`BUILD`** или клавишу **`Tab`**):
- `Создай файл src/api/server.ts с HTTP-сервером и маршрутом /health`
- `Отредактируй @src/example/calculator.ts и добавь обработку операции %`

### 3. Проектирование без изменения файлов (в режиме `PLAN`)
Нажмите **`Tab`** (загорится синяя кнопка **`PLAN`**):
- `Составь подробный план рефакторинга проекта на микросервисы`
- В этом режиме агент гарантированно не изменит ни один файл кода, пока вы снова не переключитесь в `BUILD`.

### 4. Быстрое выполнение команд в терминале через `!`
Начните сообщение с восклицательного знака **`!`**:
- `!git status`
- `!ls`
- `!cat opencode.json`

## 4. Полный список слэш-команд (`/`)

Просто введите `/` в поле ввода, чтобы увидеть подсказки:

| Команда | Что делает |
|---|---|
| `/init` | Автоматически анализирует проект и создаёт/обновляет файл инструкций `AGENTS.md` |
| `/review` | Проводит код-ревью изменений в проекте, проверяет баги и запускает `lsp_diagnostics` |
| `/models` | Открывает окно выбора бесплатных ИИ-моделей (`$0 / Free`) и провайдеров |
| `/agent` | Переключает активного агента (`Build` ↔ `Plan`) |
| `/undo` | Отменяет последний шаг диалога и возвращает файлы к предыдущему состоянию |
| `/redo` | Возвращает отменённый шаг и изменения файлов |
| `/compact` | Сжимает длинную историю переписки для экономии контекстного окна токенов |
| `/diff` | Открывает вкладку просмотра всех изменений файлов (unified diff) |
| `/new` | Создаёт новую чистую сессию |
| `/sessions` | Открывает список сохранённых сессий |
| `/themes` | Переключает цветовую тему оформления |
| `/mcp` | Открывает управление серверами MCP |
| `/terminal` | Открывает или скрывает панель встроенного терминала |
| `/status` | Выводит статистику текущей модели, агента, расхода токенов и стоимости (`$0.00`) |
| `/export` | Скачивает всю переписку текущей сессии в файл Markdown (`.md`) |
| `/help` | Выводит полную справку по командам и горячим клавишам |
